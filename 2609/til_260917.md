# 📘 [학습 일지] Domain, IP, Port, DNS와 hosts 파일 실습

> **일시:** 2026년 9월 17일  
> **주제:** 웹 통신의 기초(IP, Port, Domain) 및 Name Resolution, Windows hosts 파일 수정 실습  
> **학습 방식:** 1:1 질의응답 중심의 개념 검증, 로컬 이름 해석 원리 파악 및 네트워크 흐름 정리  

---

## 1. 웹 주소(URL)의 핵심 구성 요소

* **URL 예시:** `http://10.2.16.254:8000/`
  - **Protocol (`http`):** 어떤 방식(규약)으로 통신할 것인가?
  - **IP Address (`10.2.16.254`):** 어느 컴퓨터(서버)로 접속할 것인가? (비유: 건물 주소)
  - **Port (`8000`):** 그 컴퓨터 안의 어떤 프로그램(서비스)으로 접속할 것인가? (비유: 건물 호실)

---

## 2. IP Address & Port의 역할

* **IP Address:** 네트워크 상에서 컴퓨터를 식별하기 위한 숫자 주소.
  - **사설 IP (Private IP):** `10.x.x.x`, `172.16~31.x.x`, `192.168.x.x` 등 내부 네트워크(학원, 회사 등)에서만 접근 가능한 주소.
* **Port:** 하나의 서버에서 여러 프로그램(웹 서버, DB 서버, SSH 등)이 실행될 때, 들어온 요청을 처리할 앱을 구분하는 번호.
  - 주요 포트: HTTP(`80`), HTTPS(`443`), SSH(`22`), MySQL(`3306`), PostgreSQL(`5432`), Django 개발서버(`8000`)

---

## 3. Domain Name, DNS, Name Resolution

* **Domain Name:** 사람이 기억하기 어려운 숫자로 된 IP 주소 대신 사용하는 문자 이름 (예: `google.com`, `kant.test`).
* **Name Resolution (이름 해석):** 도메인 이름을 실제 네트워크 통신에 필요한 IP 주소로 변환하는 과정.
* **DNS (Domain Name System):** 인터넷의 전화번호부 역할을 수행하며, 도메인 이름에 해당하는 IP 주소를 알려주는 시스템.
* **주의:** DNS는 웹페이지 내용을 가져다주는 것이 아니라, **"접속할 서버의 IP 주소가 무엇인지"**만 알려주는 역할을 한다.

---

## 4. [실습] Windows hosts 파일을 활용한 로컬 Name Resolution

### 💡 hosts 파일 개념
* 자신의 컴퓨터에 저장된 작은 개인용 '이름-IP 연결 주소록'.
* DNS 서버를 거치지 않고 내 PC에서만 작동하는 로컬 이름 해석 규칙을 지정할 수 있다.

### 💡 실습 단계
1. **IP 접속 확인:** `http://10.2.16.254:8000/` 접속 가능 여부 먼저 확인.
2. **관리자 권한 실행:** 메모장을 '관리자 권한으로 실행' 후 `C:\Windows\System32\drivers\etc\hosts` 파일 열기 (파일 형식을 '모든 파일'로 변경).
3. **매핑 등록:** 파일 하단에 `10.2.16.254    kant.test` 추가 후 저장.
   - `.test` 확장자는 테스트용 예약 도메인으로, 실제 인터넷 서비스와의 충돌을 방지한다.
4. **검증 및 캐시 초기화:**
   - PowerShell/CMD에서 `ipconfig /flushdns`로 DNS 캐시 정리.
   - `ping kant.test` 명령 실행 시 `[10.2.16.254]`로 이름 해석되는지 확인.
5. **브라우저 접속:** `http://kant.test:8000/`으로 접속하여 기존 IP 접속과 동일한 결과 확인.

---

## 5. 브라우저에서 서버까지의 전체 흐름 요약

1. **사용자 입력:** 브라우저 주소창에 `http://kant.test:8000/` 입력.
2. **Name Resolution:** `hosts` 파일(또는 DNS)을 참조하여 `kant.test` ➔ `10.2.16.254` IP 주소 획득.
3. **Web Server 접속:** `10.2.16.254` 서버의 `8000`번 포트로 HTTP 요청 전달 (예: Django).
4. **DB Server 연동:** 웹 서버 필요 시 DB 서버(`PostgreSQL`: `5432` 포트)에 SQL 조회 후 결과를 받아 사용자에게 HTML 응답 반환.

---

## 6. Today's Takeaway

* 사람은 **Domain Name**을 사용하고, 컴퓨터는 **Name Resolution (hosts / DNS)**을 통해 **IP Address**를 찾은 뒤, **Port**를 통해 목적지 프로그램에 최종 접속한다.
* `hosts` 파일 수정은 실제 DNS 서버를 만든 것이 아니라, 내 컴퓨터 내부의 로컬 이름 해석 규칙을 추가한 것임을 명확히 이해했다.
