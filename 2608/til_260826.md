## 1. Chapter 14: 함수 (Function)

### 1) 핵심 학습 목표
* `def`로 함수를 정의하고 호출하는 방법 습득.
* 함수 정의와 호출의 차이, 매개변수(Parameter)와 인수(Argument)의 차이 이해.
* `return`과 `print()`의 역할 구분 및 반환값 활용.
* 기본값 매개변수, 키워드 인수, 가변 인수(`*args`) 활용.
* 지역 변수의 스코프(범위) 이해.
* 긴 코드를 역할별 작은 함수로 분할하는 리팩토링 능력 배양.

### 2) `def` 함수 기본 구조 및 이름 규칙
* **정의와 호출의 차이:**
  * **정의 (`def`)**: 함수의 역할과 동작을 선언만 해두는 단계.
  * **호출 (`func()`)**: 만들어 둔 함수를 실행하는 단계.
* **함수 이름 작명 권장 사항:**
  * 역할이 명확히 드러나도록 동사 중심의 **스네이크 케이스(snake_case)** 사용 (`a()`, `f1()` ❌ / `calculate_total()` ⭕).
* **매개변수 vs 인수:**
  * **매개변수 (Parameter)**: 함수 정의 시 입력값을 받아두기 위해 선언하는 변수.
  * **인수 (Argument)**: 함수 호출 시 실제로 넘겨주는 데이터.

## 2. 파이썬 주요 데이터 타입 및 문법 개념 Q&A

### 1) 가상환경(Virtual Environment, `venv`)을 만드는 이유
* **프로젝트 간 패키지 버전 충돌 방지:** 프로젝트마다 독립된 환경을 만들어 라이브러리 버전이 서로 꼬이는 현상을 방지.
* **시스템 환경 유지:** 컴퓨터 중앙 파이썬 환경을 더럽히지 않고 프로젝트 단위로 깔끔하게 관리 및 삭제 가능.
* **협업 및 배포 용이성:** `requirements.txt`를 공유하여 환경을 동일하게 1초 만에 복제 가능.

### 2) 문자열(`str`) 비교 메커니즘
* **사전순(Lexicographical Order) 비교:**
  * 앞에서부터 한 글자씩 비교하며, 문자 자체의 **유니코드/ASCII 숫자 값**을 기준으로 크기를 판단.
* **주요 비교 규칙:**
  * 알파벳 대문자가 소문자보다 작음 (`'A'` < `'a'`).
  * 숫자 형태 문자열은 크기가 아닌 **첫 글자의 아스키 값**으로 비교함 (`'100'` < `'20'` 은 `True`).
  * 길이가 다르고 앞부분이 같으면 짧은 글자가 작음 (`'app'` < `'apple'`).
* **관련 함수:**
  * `ord(문자)`: 문자의 ASCII/유니코드 숫자 값 반환 (예: `ord('A')` $\rightarrow$ `65`).
  * `chr(숫자)`: 숫자 값을 해당하는 문자로 변환 (예: `chr(65)` $\rightarrow$ `'A'`).

### 3) 숫자 형태 문자열과 정수 비교의 차이
* 진짜 숫자 타입(`int`, `float`)끼리는 실제 크기 비교 (`100 > 20` $\rightarrow$ `True`).
* 문자열 타입(`str`) 끼리는 아스키 순서 비교 (`"100" > "20"` $\rightarrow$ `False`).
* 따라서 문자로 된 숫자는 `int()`나 `float()`로 **형변환(Casting)** 후 비교해야 안전함.

## 3. Chapter 15: 모듈, 패키지 및 가상환경

### 1) 핵심 학습 목표
* 모듈(`.py`) 및 패키지(폴더) 구조 이해 및 `import` 활용.
* `import module`, `from module import name`, `import module as alias` 구문 차이 구분.
* 표준 라이브러리와 외부 패키지 차이 이해 및 `python -m pip` 활용.
* `venv`를 통한 환경 설정, VS Code 인터프리터 선택, `requirements.txt` 활용.
* `ModuleNotFoundError` 예외 발생 시 경로 및 환경 점검 능력 배양.

### 2) 모듈 별칭(Alias, `as`) 및 작명 규칙
* `import statistics as stats`와 같이 `as` 키워드를 사용하여 짧은 별칭을 지정할 수 있음.
* **변수 작명 규칙 동일 적용:**
  * 별칭도 내부적으로 변수처럼 동작하므로 파이썬 변수 이름 규칙이 100% 동일하게 적용됨 (첫 글자 숫자 불가, 특수문자/공백 불가, 키워드 사용 불가).
* **개발자 관례(Convention):**
  * `statistics` $\rightarrow$ `stats`
  * `numpy` $\rightarrow$ `np`
  * `pandas` $\rightarrow$ `pd`
  * `matplotlib.pyplot` $\rightarrow$ `plt`

### 3) 모듈 함수 호출 및 인자 전달 실습 오류 분석

```python
import math_tools

# 5번째 줄: 정상 작동
print(math_tools.average([80, 90, 100]))

# 6번째 줄: TypeError 발생
print(math_tools.average(80, 90, 100))

5번째 줄이 정상 작동하는 이유:

[80, 90, 100]이라는 1개의 리스트(반복 가능한 객체)를 인수로 전달하여 함수 정의와 일치함.

6번째 줄이 에러(TypeError)가 나는 이유:

인수 개수 불일치: 함수는 매개변수를 1개만 받아들이도록 정의되어 있는데, 3개의 독립된 인수를 전달함.

반복 불가능 데이터: 80이라는 단일 정수는 sum(), len() 등 묶음 연산을 수행할 수 없는 자료형임.

해결법 (가변 인수 활용):

여러 인수를 낱개로 받고 싶다면 함수 정의 시 매개변수 앞에 *를 사용해야 함 (def average(*numbers):).
