# 파이썬 기초 챕터 요약 노트: 사용자 입력 및 조건문 기초

## 1. f-string과 에디터 문법 하이라이팅
* **`f"문자열 {변수}"` 표현식:** 문자열 앞에 `f`를 붙여 변수나 연산 결과를 직관적으로 출력하는 기능입니다.
* **에디터의 색상 강조:** 코딩 프로그램(VS Code 등)에서 `f` 글자가 빨간색/주황색 등으로 강조되는 것은 **f-string 문법임을 알려주는 정상적인 하이라이팅 기능**이며, 코드 오류(Error)가 아닙니다.

## 2. 예외 처리 (try / except)
* **개념:** 프로그램 실행 중 발생할 수 있는 에러(예외)로 인해 프로그램이 갑자기 종료(튕김)되는 것을 방지하는 제어문입니다.
* **작동 원리:**
  * `try:` 블록 안의 코드를 먼저 실행합니다.
  * 오류가 없으면 정상 진행하고, 오류가 발생하면 즉시 `except:` 블록으로 이동하여 대처 코드를 실행합니다.
* **에러 종류별 대처:**
  * `ValueError`: 문자를 숫자로 형 변환(`int()`, `float()`)할 수 없을 때 발생합니다.
  * `TypeError`: 계산할 수 없는 서로 다른 자료형끼리 연산하려 할 때 발생합니다.

## 3. 조건문과 들여쓰기 (Indentation)
* **들여쓰기의 역할:** 파이썬에서는 들여쓰기를 통해 소속 구역(블록)을 구별합니다.
* **들여쓰기 O:** `if` 조건문의 지배를 받아, **조건이 참(`True`)일 때만 실행**됩니다.
* **들여쓰기 X:** `if` 조건문과 상관없는 독립적인 코드로, **조건과 무관하게 무조건 실행**됩니다.

## 4. 불리언(Boolean) 타입과 `not` 연산자
* **불리언 타입 (`True` / `False`):** 프로그램의 **상태(스위치 ON/OFF)**를 나타내는 자료형입니다.
* **직접 지정 vs 자동 지정:**
  * 개발/테스트 시에는 변수에 `is_closed = False`처럼 직접 값을 입력합니다.
  * 실제 프로그램에서는 시간 계산이나 `input()`의 조건 판단 결과를 통해 값이 자동으로 저장되도록 구현합니다.
* **`not` 연산자:** 참과 거짓의 상태를 뒤집습니다.
  * `if not is_closed:` $\rightarrow$ "닫히지 않았다면(=열려 있다면)"으로 해석되어 직관적인 조건 처리가 가능합니다.

## 5. 문자열 공백 제거 함수 비교
* **`strip()`:** 문자열의 **양쪽 끝(앞/뒤)**에 있는 공백만 제거합니다. (중간 공백은 유지)
* **`replace(" ", "")`:** 문자열 **안쪽(중간)을 포함한 모든 공백**을 제거할 때 가장 직관적으로 사용하는 방법입니다.
* **`"".join(text.split())`:** 연속된 모든 공백을 제거하고 단어만 합치는 대체 방법입니다.
# 파이썬 기초 챕터 요약 노트: 반복문(for문) 기초 및 활용

## 1. for문의 기본 구조와 루프 변수의 역할
* **기본 형태:** `for i in range(3):`
* **루프 변수(`i`):** 반복문이 돌 때마다 생성된 값을 순서대로 하나씩 전달받아 저장하는 **임시 바구니(변수)**입니다.
* **변수명:** `i`(Index/Integer의 약자)를 관례적으로 많이 쓰지만 `num`, `char` 등 원하는 이름으로 바꿀 수 있습니다.
* **`_` (언더바) 사용:** 반복되는 숫자를 직접 사용하지 않고 **순수 반복 횟수만 필요할 때는 `for _ in range(3):`**처럼 작성합니다.

## 2. `range()` 함수 활용 및 범위 지정
* **`range(끝_숫자)`:** `0`부터 시작하여 `끝_숫자 - 1`까지의 정수를 생성합니다. (예: `range(3)` $\rightarrow$ `0, 1, 2`)
* **`range(시작, 끝)`:** `시작` 숫자부터 `끝 - 1`까지 생성합니다. (예: `range(1, 5)` $\rightarrow$ `1, 2, 3, 4`)
* **`range(시작, 끝, 간격)`:** 숫자가 커지는 간격(Step)을 지정할 수 있습니다. (예: `range(1, 6, 4)` $\rightarrow$ `1, 5`)
* **핵심 규칙:** 파이썬의 범위 지정에서 **'끝 값'은 포함되지 않습니다(미만).**

## 3. 문자열(String) 순회 및 `char`
* **`char`의 의미:** **Character(문자/글자 하나)**의 약자로, 문자열을 순회할 때 관례적으로 사용하는 변수명입니다.
* **동작 방식:** `for char in "Python":` 코드는 문자열에서 글자를 앞에서부터 한 글자씩 꺼내어 `char` 변수에 저장하며 반복합니다.

## 4. 반복문 안에서의 값 누적/카운팅
* 반복문 바깥에 초기값(예: `number = 1`)을 선언해 두고, 반복문 내부에서 `number += 1`을 실행하면 **바퀴 수가 중첩될 때마다 순차적으로 숫자를 1씩 늘리며 순서를 추적**할 수 있습니다.
