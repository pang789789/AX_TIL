3. print() 함수의 이해 및 기본 실행 흐름
print("Hello, Python!") 코드 한 줄도 파이썬은 왼쪽부터 차례대로 의미를 해석합니다.

Python
print("Hello, Python!")
3.1. 코드 구조 파헤치기
print: 화면(터미널)에 결과를 보여 달라고 지시하는 명령어(출력 명령)입니다.

( (여는 괄호): 출력할 내용의 시작을 알립니다.

" (여는 따옴표): 컴퓨터에게 명령어나 변수가 아닌, 있는 그대로의 순수한 글자(문자열)임을 알립니다.

Hello, Python!: 화면에 실제 출력될 문자 데이터입니다.

" (닫는 따옴표): 순수 글자(문자열)의 끝을 알립니다.

) (닫는 괄호): 출력할 내용의 끝을 알립니다.

4. 파이썬 기초 활용 (주석, 변수, 입력 및 f-string)
4.1. 주석 (#) 및 코드 실행 순서
파이썬 코드는 기본적으로 위에서 아래로 순차 실행됩니다. 코드에 설명을 달고 싶다면 # 기호를 사용합니다.

Python
# 1. 첫 번째 숫자와 두 번째 숫자를 변수에 저장합니다.
num1 = 10
num2 = 20

# 2. 두 숫자를 더해서 result 변수에 담습니다.
result = num1 + num2

print(f"두 수의 합: {result}")
4.2. input()과 f-string 활용하기
사용자에게 값을 직접 받으려면 input()을 사용합니다. input()으로 들어온 값은 무조건 문자열 형태가 되므로 계산 시 int()로 감싸주어야 합니다.

Python
# 사용자로부터 숫자 입력받기 (int로 형변환)
num1 = int(input("첫 번째 숫자를 입력하세요: "))
num2 = int(input("두 번째 숫자를 입력하세요: "))

# f-string을 활용해 중괄호 {} 안에 변수를 넣어 출력
print(f"입력받은 두 수의 합은 {num1 + num2}입니다.")

2. AI에게 효과적으로 질문하는 법 (Four Pillars)
코드 작성 중 오류가 발생하거나 막힐 때는 단순히 완성된 코드를 달라고 요청하기보다 단계별 힌트와 원인을 질문하는 것이 장기적인 성장에 훨씬 유리합니다.

2.1. 좋은 질문을 구성하는 4가지 핵심 요소
환경 정보 (Environment): OS, 개발 환경, 파이썬 버전 명시 (예: Windows 11, VS Code, Python 3.14)

실행한 명령 (Executed Command): 터미널에서 실제로 입력하고 실행한 명령 전체

오류 메시지 (Exact Error Message): 캡처 이미지 대신 터미널의 에러 로그 전체 텍스트 복사

원하는 도움 (Goal / Requested Help): 문제의 원인 설명 및 최소한의 수정 방향 요청

⚠️ 주의사항: 비밀번호, API 키, 개인정보 등 민감한 정보는 반드시 가리거나 삭제한 후 질문해야 합니다.

3. print() 함수와 기본 실행 흐름
3.1. 코드 구조 파헤치기
파이썬은 코드를 읽을 때 위에서 아래로, 그리고 왼쪽에서 오른쪽으로 순차 해석합니다.

Python
print("Hello, Python!")
print: 화면(터미널)에 결과를 출력하라고 명령하는 함수입니다.

( (여는 괄호): 출력할 데이터 범위의 시작을 나타냅니다.

" (여는 따옴표): 단순 명령어나 변수가 아닌, 있는 그대로의 문자열(String) 데이터임을 표시합니다.

Hello, Python!: 화면에 실제 표시될 문자 데이터입니다.

" (닫는 따옴표): 문자열 데이터의 끝을 나타냅니다.

) (닫는 괄호): 출력 명령 범위의 끝을 나타냅니다.

4. 파이썬 기초 문법 활용
4.1. 주석 (#) 및 코드 순차 실행
파이썬은 # 기호 뒤에 오는 텍스트를 실행하지 않고 무시합니다. 코드를 설명하거나 잠시 멈출 때 사용합니다.

Python
# 1. 변수에 값을 저장합니다. (위에서 아래로 실행)
num1 = 10
num2 = 20

# 2. 두 변수를 더해 result에 저장합니다.
result = num1 + num2

print(f"두 수의 합: {result}")
4.2. input() 함수와 데이터 타입 변환
input()은 사용자로부터 문자나 숫자를 입력받는 함수입니다. 입력받은 데이터는 무조건 문자열(str)로 저장되므로, 산술 연산을 하려면 int()를 통해 정수로 형변환(Type Casting)해야 합니다.

Python
# input()을 int()로 감싸 정수로 변환하여 입력받기
num1 = int(input("첫 번째 숫자를 입력하세요: "))
num2 = int(input("두 번째 숫자를 입력하세요: "))

# 두 숫자의 합 계산 및 출력
result = num1 + num2
print(f"두 수의 합은 {result}입니다.")
4.3. f-string (f"...")의 역할
문자열 시작 따옴표 앞에 f를 붙이면 f-string(Formatted String Literal)이 활성화됩니다.

중괄호 {} 안에 변수나 식을 넣으면, 파이썬이 이를 실제 값으로 치환해 줍니다.

f를 빠뜨리면 {variable}이라는 문자 그대로 출력되므로 주의해야 합니다.

5. 파이썬 핵심 문법: 들여쓰기 (Indentation)
파이썬은 C언어나 Java처럼 중괄호({})로 코드 구역을 나누지 않고, 오직 들여쓰기의 깊이로 코드의 소속 관계(Block)를 표현합니다.

Python
# 정상적인 들여쓰기 소속 예시
if True:
    print("참입니다!") # if 문에 속한 하위 코드 (스페이스 4칸 들여쓰기)
5.1. 아무 이유 없는 들여쓰기가 오류 나는 이유
파이썬 해석기(Interpreter) 입장에서 들여쓰기는 "나는 바로 위의 명령어에 속한 하위 코드입니다"라는 의미입니다.

Python
print("안녕하세요")
    print("반갑습니다") # ❌ IndentationError: unexpected indent
상위에 소속을 부여하는 조건문(if), 반복문(for), 함수(def) 등의 명령어(:)가 없는데 갑자기 들여쓰기를 하면, 파이썬은 "소속될 상위 부모가 없는데 왜 들어가 있는가?"라며 문법 파괴로 인식하고 에러를 발생시킵니다.
