## 1. 이미지 데이터 다루기 실습 과제 개요

### 1) 과제 평가 및 학습 목적
* 정답 코드 생성이 목적이 아닌 **문제 분해, 2차원 배열 이해, 조건문/반복문/함수/재귀 활용, 디버깅 및 알고리즘 설명 능력**을 평가함.
* AI를 정답 제출기가 아닌 페어 프로그래밍 파트너 및 학습 도구로 활용함.

### 2) 담당 문제: 컬러 이미지의 임계값(Threshold) 계산 및 흑백 이미지 생성
* **1단계 (문제 분해):**
  * 컬러 이미지(3차원 배열) $\rightarrow$ 흑백(Grayscale) 이미지(2차원 배열) 변환 $\rightarrow$ 임계값(Threshold) 계산 $\rightarrow$ 이진화(Binary) 이미지(0과 255) 생성
* **2단계 (데이터 구조):**
  * **컬러 이미지:** `[R, G, B]` 형태의 픽셀로 이루어진 **3차원 리스트**
  * **흑백 이미지:** 하나의 밝기값 숫자(0~255)로 이루어진 **2차원 리스트**

## 2. 파이썬 주요 자료구조 (리스트, 튜플, 집합)

### 1) 리스트 (List)
* **특징:** 대괄호(`[]`)를 사용하며, 순서(Index)가 있고 요소를 자유롭게 추가, 수정, 삭제할 수 있습니다.
* **for문 활용:**
  * 요소 직접 순회: `for item in items:`
  * 인덱스 순회: `for i in range(len(items)):`

### 2) 튜플 (Tuple)
* **특징:** 소괄호(`()`)를 사용하며, 생성 후 **추가·수정·삭제가 불가능합니다(Immutable).**
* **요소가 1개인 튜플:** 단순 연산용 괄호와 구분하기 위해 **쉼표(`,`)**를 반드시 붙여야 합니다. (예: `(5,)`)
* **다양한 자료형 혼용:** `("문길동", 20, "Python")`처럼 서로 다른 타입도 한 튜플에 담을 수 있습니다.
* **패킹 & 언패킹 (Packing & Unpacking):**
  * **패킹:** 여러 값을 하나로 묶는 것 (`data = 1, 2, 3`)
  * **언패킹:** 묶여 있는 값을 개별 변수로 푸는 것 (`a, b, c = data`)
  * **값 교환(Swap):** `a, b = b, a`

### 3) 집합 (Set)
* **특징:** 중괄호(`{}`)를 사용하며, **중복을 허용하지 않고 순서가 없습니다.**
* **주요 메소드:**
  * `add(x)`: 요소 추가
  * `remove(x)`: 지우려는 값이 없으면 🚨 **`KeyError`** 발생
  * `discard(x)`: 지우려는 값이 없어도 에러 없이 무시하고 진행

## 3. 딕셔너리 (Dictionary) 상세

### 1) 기본 개념 및 규칙
* **구조:** `{Key: Value}` 형태로 데이터를 저장합니다.
* **Key (키):**
  * **유일성:** 중복 불가능 (중복 입력 시 나중 값으로 덮어씌움).
  * **불변성:** 값이 변하지 않는 **수정 불가능한(Immutable) 데이터**만 키로 지정 가능 (문자열, 숫자, 튜플 등 O / 리스트, 집합, 딕셔너리 X).
* **Value (값):**
  * 어떠한 자료형이든 가능하며, 값끼리의 중복도 허용됨.
  * `None`, 빈 리스트 `[]`, 빈 딕셔너리 `{}` 등 '비어있음'을 표현하는 데이터도 지정 가능.
  * ⚠️ 단, `{"key": }`처럼 콜론(`:`) 뒤의 값 자체를 생략하면 문법 에러(`SyntaxError`) 발생.

### 2) 안전한 Key 조회 (`KeyError` 방지)
존재하지 않는 키에 직접 접근(`dict[key]`)하면 🚨 `KeyError`가 발생합니다.

* **`in` 키워드 활용:**
  ```python
  if "subject" in student:
      print(student["subject"])
  else:
      print("키가 존재하지 않습니다.")

### get() 메소드 활용:
# 없는 키면 None 반환 (에러 안 남)
print(student.get("subject"))

# 없는 키일 때 반환할 기본값 지정
print(student.get("subject", "수강과목 없음"))
3) 딕셔너리 순회 메소드 (keys, values, items)
dict.keys(): 키(Key) 목록만 추출

dict.values(): 값(Value) 목록만 추출

dict.items(): (Key, Value) 형태의 튜플 쌍으로 추출

Python
# items()와 for문 활용 (튜플 언패킹)
student = {"name": "문길동", "age": 20, "subject": "Python"}

for key, value in student.items():
    print(f"항목({key}) : {value}")

4. 멀티모달 (Multimodal) AI 개념
정의: 텍스트, 이미지, 음성, 비디오 등 서로 다른 여러 형태(Modal)의 정보를 동시에 이해하고 처리하는 기술.

단일 모달 vs 멀티모달:

단일 모달 (Unimodal): 텍스트만 처리하거나 이미지만 전담하는 독립적 모델.

멀티모달 (Multimodal): 사람처럼 시각, 청각, 텍스트를 종합적으로 인식하여 실제 세상의 맥락을 정확하게 파악하는 모델.

입출력 형태 및 활용 예시:

텍스트 + 이미지 → 텍스트: 사진 속 식재료나 차트 분석 후 답변.

텍스트 → 이미지 / 비디오: 프롬프트 입력으로 이미지/영상 생성 (Midjourney, DALL-E, Sora 등).

음성 + 시각 → 음성: 실시간 대화 및 상호작용 (GPT-4o, Gemini Live 등).
