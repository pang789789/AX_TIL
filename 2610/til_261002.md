## 1. 웹 애플리케이션 전체 구조

[Browser (Client)] -- (HTTP Request) --> [Web Server / API Server]
                  <-- (HTTP Response) --

### 전체 서비스 흐름 (회원관리 예시)
Browser -> Web Server / API Server -> Backend -> Database -> JSON/HTML/CSS/JS -> Browser

### 단계별 개발 로드맵
- 1차: Browser에서 Frontend 제작 및 제공 API 활용 (Live Server 사용)
- 2차: FastAPI로 API Server 직접 구현
- 3차: React/Next.js + FastAPI/PostgreSQL 통합

## 2. Web Server vs API Server

| 구분 | Web Server | API Server |
| :--- | :--- | :--- |
| **제공 자원** | HTML, CSS, JavaScript, 이미지 파일 | 데이터 및 기능 (JSON 형식) |
| **실습 도구** | **VS Code Live Server** (정적 Web Server) | Provided API (1차) / FastAPI (2차) |
| **요청/응답** | [http://127.0.0.1:5500/](http://127.0.0.1:5500/) -> index.html | GET /members -> [{"id": 1, "name": "Kim"}] |

---

## 3. localhost와 포트(Port)

* **localhost (127.0.0.1)**: 현재 내가 사용 중인 컴퓨터 자신을 가리킴
* **포트(Port)**: 한 컴퓨터 내부에서 실행 중인 여러 서버 프로그램을 구분하기 위한 번호
  - 예: http://localhost:5500/ -> http(통신 방식) / localhost(내 컴퓨터) / 5500(프로그램 포트 번호)

## 4. 브라우저의 3요소 & 개발 도구

### 브라우저 3요소
1. **HTML**: 정보 구조 (골격)
2. **CSS**: 표현과 배치 (디자인)
3. **JavaScript**: 데이터와 동작 (행동)

### 핵심 개발 도구
* **VS Code**: 코드 및 프로젝트 파일 작성
* **Live Server**: HTML/CSS/JS를 HTTP로 제공하는 정적 Web Server
* **Chrome / Edge**: Frontend가 실행되는 브라우저 환경
* **DevTools (F12)**:
  - Elements: HTML/DOM 및 CSS 구조 확인
  - Console: JS 실행 결과 및 오류 출력
  - Network: HTTP Request/Response 상태 확인

## 5. 실습 및 Git 워크플로우

### STEP 01. Repository Fork & Clone
git clone [https://github.com/내아이디/fullstack-web-course.git](https://github.com/내아이디/fullstack-web-course.git)
cd fullstack-web-course
git status

### STEP 02. 실습 폴더 및 HTML 생성
- 경로: practice/phase01/chapter01/index.html

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Frontend 첫 실습</title>
</head>
<body>
  <h1>Frontend 학습을 시작합니다.</h1>
  <p>첫 번째 웹페이지입니다.</p>
</body>
</html>

### STEP 03. Live Server 실행 & 검증
- index.html 열기 -> 우클릭 -> Open with Live Server
- 주소 확인: [http://127.0.0.1:5500/practice/phase01/chapter01/index.html](http://127.0.0.1:5500/practice/phase01/chapter01/index.html)
- Network 탭 검증: index.html 요청 선택 -> Request Method: GET, Status Code 확인

### STEP 04. Git Commit & Push
git status
git add practice/phase01/chapter01/index.html
git commit -m "Complete phase01 chapter01 web server practice"
git push origin main
